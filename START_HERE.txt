WALL IMAGE CLASSIFICATION — MIDTERM PROJECT

All models are trained on the supplied BD3 images. There are no pretrained
networks or downloaded model weights in this project.

OPEN FIRST
report.docx          First-person report, including Tasks 5, 6 and 7.
notebook.ipynb        Main workflow: four classifiers, 5-fold CV and tuning.
cnn_training.ipynb    Extra experiment: a small CNN trained from random weights.
app.py               Simple local image-upload demonstration.

The default website model is tuned Random Forest, chosen through the classical
CV comparison. Select another model to compare predictions. The CNN is an extra
experiment with a separate validation set; it did not participate in that CV
ranking. All six test results use the same 584 images. Earlier project versions
also used this holdout, so these results are not a fresh blind benchmark.

RUN THE WEBSITE
Use Python 3.12. Open a terminal inside this project folder and run:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

On Windows, activate with .venv\Scripts\activate instead.
Open http://127.0.0.1:8501 in a browser. Choose a model, upload a JPG, PNG or WebP,
and click Classify. Seven example test images are in test_images/.
The saved models are included, so the demo does not require retraining or the
full dataset. Installation requires internet; prediction runs locally.

RUN THE NOTEBOOKS
Open notebook.ipynb in Jupyter or VS Code and choose this Python environment.
Place BD3_original_dataset beside the notebook, or update DATASET in its first
code cell. The supplied dataset is not duplicated inside this archive.
Run all cells in order. This repeats the real training, CV, grid search and
held-out evaluation. It takes several minutes on a CPU. The delivered main
notebook already contains executed outputs.

The CNN notebook contains the full training/evaluation code and clearly marked
recorded output from the completed 30-epoch run. Running all its cells trains a
new CNN and replaces the saved CNN weights and metrics. CPU versions or hardware
can affect numerical results and runtime. Neither notebook downloads weights.

DATA AND EVALUATION
The original 3,965 images were checked for exact pixel duplicates. I excluded
61 extra same-label copies and 11 conflicting-label files, leaving 3,893 images.
results/split_manifest.csv records every retained path, class, split and hash;
results/excluded_images.csv records exclusions. Images are not modified.
Classical models use 3,309 development images and 584 test images. Each model
gets the same five stratified CV folds. LR and KNN scaling happens inside each
fold. Highest mean CV macro F1 selects the model for GridSearchCV.
Random Forest tuning searches three parameters: max_depth, min_samples_leaf,
and max_features. Eight combinations produce 40 fold fits, followed by refit.
The best CV score reuses the selection folds and is not nested CV.
CNN uses the original 2,725 training / 584 validation / 584 test split and picks
its epoch using validation macro F1. Test images never select an epoch.

RESULT FILES
model_comparison.csv       Test metrics and recorded example timing for all models.
per_class_metrics.csv      Precision, recall, F1 and support for every class/model.
cv_summary.csv             Five-fold mean and sample standard deviation.
cv_folds.csv               Individual fold scores, including training scores.
classical_results.json     Full classical settings, metrics and confusion matrices.
grid_search_results.json   Every tried Random Forest setting and fold metrics.
notebook_*.csv/json/png    Outputs from the separately executed main notebook.
cnn_metrics.json           CNN metrics, settings and confusion matrix.
cnn_history.csv            All 30 CNN training and validation epochs.
All these files are in results/. Figures are also saved there.
Scores use 0–1 in CSV files. Macro scores weight the seven classes equally.
Balanced accuracy equals macro recall for this multiclass task. Timing is an
example measurement, changes between runs, and excludes image preprocessing
for prediction. CNN epoch timing includes validation. It is not directly
comparable to classical final-fit timing. A blank CNN development accuracy
means it was not measured over the combined classical development subset.

SCOPE
This is a classroom MVP: one upload, one class label, and a comparison table.
It always assigns one of the seven labels, even to an unrelated image. Similar
scenes can remain across splits because building IDs are unavailable. New
buildings would be a stronger test. If retraining changes results, update the
report and combined result files before submission.
